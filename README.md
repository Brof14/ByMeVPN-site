# ByMeVPN Website

The static website for the ByMeVPN product. This repository contains the site entry point and the custom-domain configuration used for its web presence.

## Contents

- `index.html` — website markup, styles, and client-side behavior
- `CNAME` — custom-domain configuration for GitHub Pages
- `photo_2026-05-28_18-36-54.jpg` — image asset used by the site

## Development

This is a static HTML site; no package manager or build step is defined in the repository. Edit `index.html` and review the rendered page before publishing changes.

GitHub Pages deployment and DNS depend on the repository's Pages settings and domain configuration. Avoid changing the `CNAME` file unless the domain routing is being updated intentionally.
