# ByMeVPN-site — design and product audit

Date: 2026-11-15
Base: main commit 72f006d43d43aaeb1094e76b3249795365211c5e
Redesign branch: design/bright-product-first-20261115

## Why the previous design fell short

- The dark navy first screen and narrow phone mock looked like a generic technology showcase, whereas the requested references make product actions and imagery the immediate center of attention.
- Repeated abstract rings, small labels and uniform dark sections diluted the visual identity.
- Product concepts, prices and trial promises were spread across multiple blocks and did not form a strong sales narrative.
- The prior assistant's 91/100 score was not supported by user validation or objective design research.

## Reference findings

Reference 1: https://platipomiru.com/ — light fintech canvas, blue color hierarchy, direct Telegram onboarding, oversized functional illustrations, clear tariff comparisons and detailed FAQ. We do NOT replicate any logos, partnerships, sales figures, awards or its original artwork.

Reference 2: https://cash.app/ — confident oversized typography, strong product-centered visuals, separate visual treatment for each section, bold brand colors and very clear CTAs. We do NOT copy its artwork, green brand or proprietary interface.

## Design changes

1. Replaced almost-black uniform landing with cool white, blue and mint brand architecture.
2. Introduced a large hero headline, conspicuous CTA and giant blue circular product composition with a realistic app UI mockup.
3. Added a truthful, compact number strip: 3 trial days, up to 10 devices, +15 referral days. No fabricated user counts.
4. Reorganized feature benefits as an intentionally asymmetric hero scene + two differentiated illustrated panels.
5. Built a cobalt-blue interactive product chapter with functional visual-only connection states and a prominent simulation disclaimer.
6. Added an illustrated 3-step Telegram setup and a clearly differentiated referral invitation panel.
7. Retained full pricing transparency: 2/5/10 devices, 1/4/8/15-month billing periods, per-month display and full upfront totals.
8. Reworked mobile nav and responsive composition for 320–1920px; maintained keyboard focus, ARIA, reduced-motion.
9. Kept the existing font assets, optimized for local serving and no third-party scripts or trackers.

## Verified product rules from ByMeVPN_bot/constants.py

- REFERRAL_SIGNUP_BONUS_DAYS = 15
- VALID_DEVICE_LIMITS = (2, 5, 10)
- BASE_MONTHLY_PRICES = {1:89,3:79,6:69,12:59}
- DEVICE_PRICE_EXTRA = {2:0,5:20,10:40}
- TARIFF_BONUS_MONTHS = {1:0,3:1,6:2,12:3}

The final production price and subscription eligibility must still be verified in the live bot, since these are repo constants, not direct backend responses. The public release of native apps cannot be assumed; no signed APK is advertised. The UI demonstration never creates a VPN tunnel.

## Release acceptance

- Static Python tests and JS syntax.
- Real Chromium screenshots at 320x740, 390x844, 768x1024, 1440x900 and 1920x1080.
- Functional tier recalculation, full upfront amounts, demo states, FAQ, mobile menu and Escape.
- No broken local images, no external network dependencies, no horizontal overflow, reduced-motion.
- Final visual human review of screenshot artifacts.
- GitHub Pages deployment success; external custom domain and real device/production business testing are separate.

## Scoring caveat

Subjective design reviews are not a substitute for user preference, WCAG audit, Lighthouse Core Web Vitals or measured paid conversion. We do not claim a literal 100/100 without those results.
