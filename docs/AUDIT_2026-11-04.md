## 3. Проверка ошибок предыдущей версии
PR #4 (`959bd9d`) уже исправил конфликт `is-revealed` / `is-visible`, четыре grid-ряда, fallback при отсутствии JavaScript/IntersectionObserver. Изменения сохраняют `data-reveal`, ровно 14 reveal-секций, четыре сцены и существующие тестовые контракты. Не заменять анимацию тяжёлой canvas-библиотекой и не прятать HTML до старта JS.

## 4. Что намеренно НЕ заявляется
- Нет выдуманной скорости, серверных регионов, гарантии No-Logs или полной анонимности.
- Нет неподтверждённых цен, «бесплатного trial без карты» в рекламе или публичной ссылки на debug APK.
- Нет имитации реального VPN-туннеля: всё состояние телефона на сайте локальное.
- Условия оплаты, списаний, лимиты устройств и способы отмены проверяются пользователем в актуальном боте.

## 5. Критерии релиза (требуют проверки в CI и браузере)
1. Python contract tests, `node --check app.js`, Playwright QA зелёные.
2. Главная CTA и header ведут к `https://t.me/ByMeVPNbot`; поддержка к `https://t.me/ByMeVPNSupportBot`.
3. На 320, 390, 768, 1440 и 1920 px отсутствуют горизонтальный overflow и скрытые текстовые блоки.
4. Мобильное меню, демо из 4 состояний, серверный sheet, Escape/focus, все FAQ, reduced-motion работают.
5. Android-скачивание не обещает публичной APK до подписанного/проверенного релиза.
6. Перед объединением в main — ручной visual review на реальном телефоне и desktop, проверка GitHub Pages/CNAME и HTTPS.

## 6. Открытый технический долг
- Рефакторинг `--tone-*` в семантические дизайнерские токены после защиты визуальными регрессиями.
- По результатам реальных просмотров решить, не стоит ли укоротить мобильную scroll-story ещё сильнее.
- Собрать и утвердить реальные, юридически корректные тарифы из production API; только затем добавлять полноценную pricing-секцию.
- Добавить verified Android release CTA через signed APK / Google Play, когда действительно готова публикация.
- Снять измерения Lighthouse, INP/LCP/CLS и проверить сетевой waterfall в реальном браузере.
