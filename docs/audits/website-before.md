# Аудит сайта до редизайна

Дата: 1 ноября 2026 года. Источник: локальный клон `Brof14/ByMeVPN-site`, ветка `codex/effortless-connection-redesign`, исходный commit `0fd1706d83c1dfa32b5b4fa3e012e8035d05de73`. Перед снимком ветка была чистой.

## Что уже работало и сохранится

- Одностраничная статическая архитектура без зависимости от API сайта; CNAME и способ публикации остаются прежними.
- Семантические секции и якоря `#top`, `#product`, `#benefits`, `#how`, `#plans`, `#faq`, ссылка пропуска к `#main`.
- Основные действия ведут к официальным Telegram-боту и поддержке. Мобильное меню закрывается по Escape, клику вне меню и выбору ссылки.
- Палитра сайта совпадает с опубликованной палитрой Android-приложения: темно-синий фон и мятный акцент.

## Проблемы первого экрана

- Заголовок занимает четыре строки и повторяет общее обещание о свободе/простоте вместо того, чтобы объяснить, куда идти пользователю.
- Две кнопки и две дополнительные строки появляются рядом с заголовком; CTA теряется среди обещаний.
- Телефон содержит демонстрационное подключение к «Германии», таймер и слова о проверенном соединении. Эти данные не подтверждены реальным запуском VPN и текущим production-сервером.
- Текст телефона очень мелкий; нижняя панель закрывает экран приложения. На 390 px содержимое частично обрезано под сгибом.
- Горизонтальное переполнение: Hallmark измерил `scrollWidth` 333 px при 320 px и 391 px при 375 px; на 390 px визуально присутствует горизонтальная полоса прокрутки.

## Проблемы достоверности

- Статическая страница обещает «три дня бесплатно без карты» и повторяет это обещание в нескольких местах. Код бота одновременно содержит старую кампанию «3 дня за 1 ₽ с автопродлением 89 ₽ за 30 дней» и другой free-trial flow; по исходникам нельзя установить действующую production-ветвь.
- На странице опубликованы цены для плана на два устройства (89/316/552/885 ₽). Клиентский API требует подтверждения сервером и может выключать покупки по умолчанию. Цены из констант репозитория не доказывают текущую цену production.
- Windows-клиент имеет экспериментальный статус; публичного стабильного выпуска не найдено. Linux-доступность не подтверждена исходниками в объёме этого аудита. Надпись «в разработке» для всех трёх платформ слишком уверенная.
- Продуктовый экран представляет подключение, расположение и подтверждение сервера как настоящее состояние, хотя это HTML-визуализация.

## Дизайн и структура

- Hero — стандартная пара «текст слева / небольшой телефон справа»; телефон не задаёт композицию и не ведёт рассказ о продукте.
- Световой ореол, стеклянные панели, tracked-cap overlines, длинные строки и сетки однотипных карточек добавляют декоративные сигналы без нового доказательства.
- Секции повторяют одну схему «лейбл + заголовок + карточки»; на странице 10 секций, несколько CTA дублируют один и тот же trial.
- Удалённый PNG логотипа загружается с `raw.githubusercontent.com`; изображение не локализовано.

## Проверки Hallmark до редизайна

Команда `sloplint.mjs work/ByMeVPN-site --genre atmospheric --render --url http://127.0.0.1:8000/ --before` записала 10 PNG-снимков в `.hallmark/before` (1280×800, 1440×900, 1920×1080 и полные страницы 1440/375). Отчёт: **133 FAIL, 99 REFLEX, 18 WARN**. Основные группы: горизонтальный скролл, несистемные цвета/шрифты, маленькие подписи, выдуманные/непроверенные строки и значения, трипированные лейблы, лишний световой эффект, обрезанный экран приложения. Записано 8 ссылок, 0 полей, 0 обработчиков, 0 test hooks и 3 script hooks; их поведение, навигация и footer должны остаться рабочими.
