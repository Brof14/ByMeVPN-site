# Аудит ByMeVPN после продуктового редизайна

**Дата:** 2026-11-02 · **Ветка:** `codex/bymevpn-product-story` · **База:** `origin/main` (`b198002`)

## Что изменилось

- Лендинг собран заново вокруг крупного Android-макета: центрированный hero, выключенная кнопка Android-загрузки и отдельная ссылка на обзор приложения.
- Демо показывает четыре сцены: VPN выключен, подключение, VPN запущен и выбор сервера. Кнопка питания воспроизводит локальную последовательность; доступен ручной выбор сцен.
- Выбор сервера возвращает фокус на управляющую кнопку, Escape закрывает экран. Подтверждён только вариант «Автоматически»; список серверов не выдуман.
- Нижние вкладки макета соответствуют текущему Android UI: Главная, Настройки, Аккаунт. На домашнем экране исходное состояние сервера — «Сервер не выбран».
- Публичного Android-релиза нет. Кнопки скачивания отключены; ни APK, ни Google Play, ни Telegram не подменяют ссылку на релиз.
- Переработаны продуктовые секции, статус Android, блок «Как начать», условия, FAQ и мобильное меню. Демо не запускает сеть.

## Проверки

- `py -m unittest discover -s tests -v` — 12 контрактных проверок пройдены.
- `node --check app.js` и `git diff --check` — пройдены.
- Chromium прошёл ширины 320×800, 360×800, 375×844, 390×844, 768×1024, 900×900, 1280×800, 1440×900 и 1920×1080; `documentElement.scrollWidth` и `body.scrollWidth` равны ширине окна на всех размерах.
- В браузере проверены мобильное меню и Escape, FAQ, четыре сцены, переход «выключен → подключение → запущен → выключен», автоматический выбор сервера и возврат фокуса, reduced motion.
- Ошибок консоли и JavaScript не было; внешние сетевые запросы со страницы не выполнялись.
- Скриншоты, матрица viewport и короткая запись переходов сохранены в `outputs/bymevpn-v3/visual/`.

## Границы изменения

`CNAME`, GitHub Pages workflow и production deployment не менялись. Изменение готовится отдельным PR от свежего `main`; merge и публикация не выполнялись. Публичная загрузка Android остаётся недоступной до проверенного официального релиза.
